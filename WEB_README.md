# Веб-приложение "Технологическое древо"

Веб-версия приложения для просмотра и отслеживания прогресса в технологическом древе, оптимизированная для использования на смартфонах.

## Описание

Это веб-приложение представляет собой конвертацию основного окна (без редактора) из `tech_tree.py` в удобный веб-интерфейс. Приложение позволяет:

- Просматривать список технологий с цветовой индикацией статуса
- Выбирать технологию и видеть её описание
- Визуализировать граф зависимостей технологий
- Отмечать технологии как выполненные
- Сохранять и загружать прогресс
- Масштабировать и перемещаться по графу
- Фильтровать и сортировать технологии

## Установка и запуск

### Требования

- Python 3.7 или выше
- pip (менеджер пакетов Python)

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск приложения

```bash
python app.py
```

Приложение будет доступно по адресу: `http://localhost:5000`

Для доступа с других устройств в локальной сети используйте IP-адрес вашего компьютера, например: `http://192.168.1.100:5000`

### Запуск на продакшен сервере

Для продакшен развертывания рекомендуется использовать gunicorn:

```bash
pip install gunicorn
gunicorn -w 4 -b 0.0.0.0:5000 app:app
```

## Использование

### Основной интерфейс

1. **Список технологий** (левая панель, снизу):
   - Зеленый цвет - выполненные технологии
   - Желтый цвет - доступные технологии
   - Красный цвет - недоступные технологии
   - Клик по технологии - выбор и отображение информации

2. **Описание технологии** (левая панель, сверху):
   - Показывает описание выбранной технологии

3. **Визуализация графа** (правая панель):
   - Отображает древо зависимостей выбранной технологии
   - Родители - сверху, дети - снизу

### Управление на компьютере

- **Выбор технологии**: Клик левой кнопкой мыши на узле
- **Отметить как выполненное**: Правая кнопка мыши на узле (или Ctrl+Click)
- **Перемещение графа**: Зажать левую кнопку и тянуть
- **Масштабирование**: Колесо мыши

### Управление на мобильном устройстве

- **Выбор технологии**: Короткое нажатие на узел
- **Отметить как выполненное**: Долгое нажатие (>0.5 сек) на узел
- **Перемещение графа**: Тянуть одним пальцем
- **Масштабирование**: Жест "щипок" двумя пальцами

### Кнопки управления

- **Сохранить прогресс**: Сохраняет прогресс в localStorage браузера
- **Загрузить прогресс**: Загружает сохраненный прогресс
- **Сбросить прогресс**: Удаляет весь прогресс
- **Вид 1/2/3**: Переключение режимов отображения графа
- **?** (кнопка справки): Показывает подробную инструкцию

### Фильтры и сортировка

- **Фильтр**: Показывать все/доступные/выполненные/недоступные технологии
- **Сортировка**: По умолчанию/по алфавиту/по статусу

## API Endpoints

- `GET /` - Главная страница
- `GET /api/technologies` - Получить список всех технологий
- `GET /api/technology/<name>` - Получить информацию о технологии
- `GET /api/tree/<name>` - Получить граф зависимостей технологии
- `POST /api/check_availability` - Проверить доступность технологий

## Особенности

- **Адаптивный дизайн**: Интерфейс автоматически подстраивается под размер экрана
- **Touch-friendly**: Оптимизирован для сенсорных экранов
- **Сохранение прогресса**: Использует localStorage для хранения данных
- **Интерактивная визуализация**: Canvas-based граф с поддержкой масштабирования и перемещения
- **Поддержка обоих форматов условий**: Старый (список строк) и новый (альтернативные пути)

## Технологии

- **Backend**: Flask (Python)
- **Frontend**: Vanilla JavaScript, HTML5 Canvas
- **Styling**: CSS3 с медиа-запросами для адаптивности

## Отличия от desktop версии

Веб-версия **не включает** функционал редактора (EditorWindow), так как по требованию нужно было преобразовать только основное окно. Редактирование древа производится через desktop версию `tech_tree.py`.
