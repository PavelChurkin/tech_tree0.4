# Руководство по использованию редактора

## Общее описание

Редактор технологического древа поддерживает как традиционный формат с одним путём получения технологии (AND логика), так и новый формат с альтернативными путями (OR логика между путями, AND внутри каждого пути).

## Открытие редактора

1. Запустите основное приложение: `python3 tech_tree.py`
2. Нажмите кнопку **"Открыть редактор"** в нижней части окна
3. Откроется окно редактора с визуализацией древа и списком технологий

## Работа с условиями (требованиями)

### Простой формат (AND логика)

Для технологий, которые требуют выполнения ВСЕХ условий одновременно:

1. Выберите технологию из списка
2. Нажмите **"Добавить условие"**
3. Введите название технологии-условия **без скобок**
4. Повторите для всех необходимых условий

**Пример:** Для технологии "Топливные элементы" добавляем:
```
Водород
Катализатор
```

В JSON это сохранится как:
```json
{
  "название": "Топливные элементы",
  "условия": ["Водород", "Катализатор"]
}
```

**Логика:** Требуется "Водород" **И** "Катализатор" одновременно.

### Альтернативные пути (OR логика)

Для технологий, которые могут быть получены несколькими способами:

1. Выберите технологию из списка
2. Нажмите **"Добавить условие"**
3. Введите путь **в круглых скобках**, разделяя условия запятыми: `(Условие1, Условие2, ...)`
4. Повторите для каждого альтернативного пути

**Пример:** Для технологии "Водород" добавляем:
```
(Электролиз, Вода)
(Паровая конверсия, Метан, Катализатор)
```

В JSON это сохранится как:
```json
{
  "название": "Водород",
  "условия": [
    ["Электролиз", "Вода"],
    ["Паровая конверсия", "Метан", "Катализатор"]
  ]
}
```

**Логика:** Требуется **ЛИБО** ("Электролиз" **И** "Вода"), **ЛИБО** ("Паровая конверсия" **И** "Метан" **И** "Катализатор").

### Смешанный формат

Если вы добавляете к одиночным условиям хотя бы один путь в скобках, редактор автоматически преобразует всё в новый формат:

**Добавляем:**
```
Условие1
(Условие2, Условие3)
```

**Сохраняется как:**
```json
{
  "условия": [
    ["Условие1"],
    ["Условие2", "Условие3"]
  ]
}
```

## Валидация условий

Редактор автоматически проверяет существование технологий при добавлении условий:

✅ **Правильно:**
- Если технология существует в древе, условие добавляется
- Для путей проверяются все технологии в скобках

❌ **Ошибка:**
- Если технология не найдена, выводится сообщение об ошибке
- Условие не добавляется до исправления

**Пример ошибки:**
```
Технология 'Несуществующая' не найдена в древе технологий!
```

Для путей:
```
Следующие технологии не найдены в древе:
- Несуществующая1
- Несуществующая2
```

## Редактирование условий

### Удаление условия

1. Выберите условие в списке условий
2. Нажмите **"Удалить условие"**

### Изменение условия

1. Удалите старое условие
2. Добавьте новое условие

## Визуализация

Редактор автоматически обновляет визуализацию PlantUML при изменении технологии:

- **Центральная технология** выделяется желтым цветом
- **Родители** (условия) показываются сверху/слева
- **Дети** (зависимые технологии) показываются снизу/справа
- **Стрелки** показывают направление зависимостей

При использовании альтернативных путей на графе отображаются ВСЕ технологии из ВСЕХ путей.

## Управление технологиями

### Создание новой технологии

1. Нажмите **"Новый узел"**
2. Введите уникальное название
3. Заполните описание (опционально)
4. Добавьте условия по необходимости

### Удаление технологии

1. Выберите технологию из списка
2. Нажмите **"Удалить узел"**
3. Технология будет удалена из всех условий других технологий

### Переименование технологии

1. Выберите технологию из списка
2. Измените название в поле "Название"
3. Изменения применяются автоматически (при нажатии клавиши)
4. Название обновляется везде, где технология используется как условие

## Сохранение и загрузка

### Сохранение JSON

1. Нажмите **"Сохранить JSON"**
2. Выберите имя файла и расположение
3. Древо сохраняется в формате JSON с поддержкой альтернативных путей

### Загрузка JSON

1. Нажмите **"Загрузить JSON"**
2. Выберите файл с древом
3. Редактор загрузит технологии и автоматически определит формат условий

### Сохранение изображения

1. Нажмите **"Сохранить картинку"**
2. Выберите имя файла
3. Текущая визуализация сохраняется как PNG изображение

## Сортировка

### По алфавиту
Нажмите **"Сортировка по алфавиту"** для упорядочивания технологий от А до Я.

### По графу
Нажмите **"Сортировка по графу"** для размещения:
- Сначала технологии без условий (корневые)
- Затем все остальные технологии

## Примеры использования

### Пример 1: Простая зависимость

**Задача:** Создать технологию "Бетон", требующую "Цемент" и "Вода"

1. Создайте технологии "Цемент" и "Вода" без условий
2. Создайте технологию "Бетон"
3. Добавьте условия: `Цемент` и `Вода` (без скобок)

### Пример 2: Альтернативные пути

**Задача:** Создать технологию "Электричество", которую можно получить через солнечные панели или ветрогенераторы

1. Создайте технологии: "Солнечная панель", "Солнечный свет", "Ветрогенератор", "Ветер"
2. Создайте технологию "Электричество"
3. Добавьте условия:
   - `(Солнечная панель, Солнечный свет)`
   - `(Ветрогенератор, Ветер)`

### Пример 3: Комплексный граф

**Задача:** Создать дерево производства топлива для космических кораблей

```
Ракетное топливо
├─ Путь 1: Керосин + Жидкий кислород
│  ├─ Нефть → Переработка → Керосин
│  └─ Воздух → Сжижение → Жидкий кислород
└─ Путь 2: Водород + Жидкий кислород (криогенное топливо)
   ├─ Вода → Электролиз → Водород → Сжижение → Жидкий водород
   └─ Воздух → Сжижение → Жидкий кислород
```

Реализация:
1. Создайте базовые ресурсы: Нефть, Воздух, Вода
2. Создайте технологии обработки: Переработка, Сжижение, Электролиз
3. Создайте промежуточные продукты: Керосин, Водород, Жидкий кислород, Жидкий водород
4. Создайте "Ракетное топливо" с условиями:
   - `(Керосин, Жидкий кислород)`
   - `(Жидкий водород, Жидкий кислород)`

## Советы и лучшие практики

1. **Проверяйте визуализацию** после каждого изменения для контроля структуры древа
2. **Используйте описательные названия** для лучшей читаемости
3. **Группируйте связанные технологии** для упрощения навигации
4. **Регулярно сохраняйте** изменения в JSON файл
5. **Тестируйте альтернативные пути** в основном приложении для проверки логики доступности

## Устранение неполадок

### Проблема: Условие не добавляется

**Причина:** Технология не существует в древе

**Решение:**
1. Проверьте правильность написания названия
2. Убедитесь, что технология создана в списке
3. Обратите внимание на регистр и пробелы

### Проблема: Визуализация не обновляется

**Причина:** Ошибка в структуре данных

**Решение:**
1. Проверьте, что все условия имеют правильный формат
2. Убедитесь, что нет циклических зависимостей
3. Перезагрузите файл в редактор

### Проблема: Ошибка при сохранении JSON

**Причина:** Неверная структура условий

**Решение:**
1. Убедитесь, что все скобки закрыты правильно
2. Проверьте, что запятые стоят между технологиями, а не в конце
3. Проверьте валидность всех технологий в условиях

## Горячие клавиши

- **Прокрутка визуализации:** Колесико мыши или стрелки
- **Автосохранение при редактировании:** Автоматически при изменении названия

## Закрытие редактора

При закрытии редактора все изменения сохраняются в памяти основного приложения. Чтобы сохранить изменения на диск:

1. Используйте **"Сохранить JSON"** в редакторе ДО закрытия, **ИЛИ**
2. Закройте редактор и используйте **"Загрузить древо"** → сохраните через основное приложение
